Passport Control for Models

Airports do not ask a passenger to describe their character before checking a passport. They check the document first.

AI deployment has no equivalent habit. A model arrives with a name, a version number, a benchmark page, and a vendor's assurance that it is ready. The institution then wraps permissions around it and hopes the object inside the wrapper is the one it evaluated.

That order is backwards.

Before an institution decides what a model may do, it should be able to prove which model it has received.

Identity is the missing precondition

W3C's DID Resolution work gives the problem a useful shape: an identifier should resolve to a document and metadata that a verifier can inspect. Verifiable Credentials add the attestation: an issuer can make a signed claim, and another party can check it without simply accepting a PDF or calling the issuer for permission.

For models, the passport would bind an artifact to its version, hash, evaluation record, permitted uses, and custody events. It would say more than “this is Model X.” It would say: this is the artifact that was tested, this is what it was tested against, this is who handled it, and this is when the credential expires.

A passport needs an expiry date

Trust in a model should age. Retraining changes behavior. Fine-tuning changes the domain. A newly discovered exploit changes the risk calculation. A model credential that cannot be renewed or revoked is not a trust system; it is a historical souvenir.

  • Identity: distinguish the precise artifact from its family name.
  • Attestation: record who evaluated it and what was actually tested.
  • Custody: preserve the chain from release to deployment.
  • Scope: state the uses for which the evidence applies.
  • Revocation: give institutions a way to stop trusting an old claim.

The credential is not a certificate of innocence

A signed credential does not make a model safe. It makes a claim inspectable. That distinction matters. A credential can be authentic and still describe a narrow test. A model can pass an evaluation and fail in Wolof, in a noisy clinic, or under a new prompt-injection technique. The credential system must therefore expose scope and uncertainty instead of turning a signature into a halo.

This is where African evaluation institutions matter. If the only passport offices are elsewhere, then African buyers remain dependent on someone else's definition of fitness. Local labs should issue credentials grounded in local languages, infrastructure, law, and social use. Scientific sovereignty includes the right to decide what evidence counts before a machine is admitted to public work.

The quiet infrastructure market

The commercial opportunity sits in registries, signing services, model cards that can be verified rather than merely read, revocation networks, independent evaluation labs, and deployment gates that refuse an uncredentialed artifact. Standards make the passport portable. Institutions make it meaningful.

The model is not entering a chat window anymore. It is entering a chain of responsibility. At that border, a name is not enough.

Le contrôle des passeports des modèles

Dans un aéroport, on ne demande pas à un passager de décrire son caractère avant de vérifier son passeport. On vérifie d'abord le document.

Le déploiement de l'IA n'a pas encore cette habitude. Un modèle arrive avec un nom, un numéro de version, une page de benchmarks et l'assurance du fournisseur qu'il est prêt. L'institution l'entoure ensuite de permissions et espère que l'objet à l'intérieur est bien celui qu'elle a évalué.

Cet ordre est inversé.

Avant de décider ce qu'un modèle peut faire, une institution doit pouvoir prouver quel modèle elle a reçu.

L'identité est la condition manquante

Le travail du W3C sur DID Resolution donne une forme utile au problème : un identifiant doit résoudre vers un document et des métadonnées qu'un vérificateur peut examiner. Les Verifiable Credentials ajoutent l'attestation : un émetteur peut produire une déclaration signée et une autre partie peut la vérifier sans accepter simplement un PDF ni appeler l'émetteur pour obtenir sa permission.

Pour les modèles, le passeport lierait un artefact à sa version, son hash, son dossier d'évaluation, ses usages autorisés et ses événements de garde. Il ne dirait pas seulement « voici le modèle X ». Il dirait : voici l'artefact qui a été testé, voici ce qui a réellement été testé, voici qui l'a manipulé et voici la date d'expiration du credential.

Un passeport doit expirer

La confiance dans un modèle doit vieillir. Le réentraînement change le comportement. Le fine-tuning change le domaine. Une vulnérabilité nouvellement découverte modifie le calcul du risque. Un credential qui ne peut être renouvelé ou révoqué n'est pas un système de confiance ; c'est un souvenir historique.

  • Identité : distinguer l'artefact précis de son nom de famille.
  • Attestation : noter qui l'a évalué et ce qui a réellement été testé.
  • Garde : préserver la chaîne de la publication au déploiement.
  • Périmètre : indiquer les usages auxquels les preuves s'appliquent.
  • Révocation : permettre aux institutions de cesser de faire confiance à une ancienne déclaration.

Le credential n'est pas un certificat d'innocence

Un credential signé ne rend pas un modèle sûr. Il rend une affirmation vérifiable. La distinction compte. Un credential peut être authentique tout en décrivant un test étroit. Un modèle peut réussir une évaluation et échouer en wolof, dans une clinique bruyante ou face à une nouvelle technique d'injection. Le système doit donc exposer le périmètre et l'incertitude au lieu de transformer une signature en auréole.

C'est ici que les institutions africaines d'évaluation comptent. Si les seuls bureaux de passeports sont ailleurs, les acheteurs africains restent dépendants de la définition étrangère de l'aptitude. Les laboratoires locaux doivent émettre des credentials fondés sur les langues, l'infrastructure, le droit et les usages sociaux locaux. La souveraineté scientifique comprend le droit de décider quelles preuves comptent avant qu'une machine ne soit admise au travail public.

Le marché discret de l'infrastructure

L'opportunité commerciale se trouve dans les registres, les services de signature, les fiches de modèles vérifiables plutôt que simplement lisibles, les réseaux de révocation, les laboratoires d'évaluation indépendants et les portes de déploiement qui refusent un artefact sans credential. Les standards rendent le passeport portable. Les institutions lui donnent son sens.

Le modèle n'entre plus seulement dans une fenêtre de conversation. Il entre dans une chaîne de responsabilité. À cette frontière, un nom ne suffit pas.
